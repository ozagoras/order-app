📡 NFC Tag Setup

Admin only — register chips to tables

How to find UID on iPhone: 1. Install NXP TagWriter from App Store
2. Open app → tap "Read Tags"
3. Hold phone over NFC tag
4. Copy the UID shown (e.g. 04A1B2C3D4E5F6)
